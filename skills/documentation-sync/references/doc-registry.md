# Document Registry Entry

| Field | Value |
|---|---|
| Path | `docs/...` |
| Class | CURRENT_TRUTH | HISTORICAL_SNAPSHOT | REFERENCE | GENERATED |
| Authority | who owns this document |
| Last verified | YYYY-MM-DD |
| Supersedes | path or NONE |
| Generated by | command or MANUAL |

## Rules

- A document has exactly one class.
- CURRENT_TRUTH documents carry `last_verified`.
- HISTORICAL_SNAPSHOT documents are append-only.
- GENERATED documents are rebuilt, never hand-edited.
- When a document is replaced, link the old one to the new one; do not delete history.
